# Number and Marks Toolkit

## Overview
A menu driven Python program that groups common problem solving algorithms into three modules. Made for CSE1021 - Introduction to Problem Solving and Programming.

## Features
- **number_tools.py** - factorial, Fibonacci, reverse, base conversion, GCD, prime generation, smallest divisor, prime factors, square root
- **array_tools.py** - max/min, counting, reversal, duplicate removal, partitioning, sorting, kth smallest
- **marks_tools.py** - student marks in a dictionary, average, grade, topper, rank list, grade summary
- **main.py** - menu that connects the modules, with input validation
- **tests.py** - 28 simple validation tests

## Technologies
Python 3 only. No external libraries.

## How to Run
1. Install Python 3
2. Open a terminal in the project folder
3. Run `python main.py`

## How to Test
Run `python tests.py`. It prints PASS or FAIL for each test and the total at the end.

## Syllabus Topics Used
Top-down design and modules, flowchart/algorithm implementation, expressions and tuple assignment, conditionals, while/for loops, break, functions, GCD, primes, prime factors, square root, base conversion, array reversal, counting, maximum, duplicate removal, partitioning, kth smallest, lists, tuples, sets, dictionaries.
